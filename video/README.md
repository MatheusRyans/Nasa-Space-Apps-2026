# AIneedHealth video assets

This folder contains the [Remotion](https://www.remotion.dev/) project used to produce the AIneedHealth videos: the 30-second pitch video, the narration and sound design, and the data pipeline that feeds the on-screen numbers from the real engine.

All on-screen data is simulated. Numbers shown in the videos come from `src/engine.js` through `tools/data.cjs`, not from hand-written values.

## Layout

```
src/index.jsx          Remotion entry point
src/Root.jsx           Composition registry
src/Main.jsx           30-second pitch video (composition "Main")
src/Scenes.jsx         Scene building blocks: titles, charts, panels
src/Scenes2.jsx        Scene building blocks: Bluetooth flow, analysis, impact
src/Scenes3.jsx        Scenes for the revised pitch edit
src/Hologram.jsx       Body-map hologram (SVG)
src/Background.jsx     Animated grid and constellation background
src/util.js            Palette, easing and helpers
src/data.json          Engine output consumed by the scenes (generated)
src/timing.json        Narration timing and captions (generated)
public/narration/      Narration WAV files
public/audio/          Generated sound bed
public/team/           Team photo used in the opening scene
tools/                 Generation scripts (see below)
out/                   Rendered files (ignored by git)
```

## Requirements

- Node.js 18 or later
- Python 3.11 or later, only for the neural voice scripts (OmniVoice requires 3.11+)
- A GPU is optional; all rendering runs on the CPU

Install the Node.js dependencies once:

```bash
npm install
```

## Common commands

| Command | What it does |
| --- | --- |
| `npm run studio` | Opens Remotion Studio to preview the compositions |
| `npm run data` | Runs the engine on the simulated scenarios and writes `src/data.json` |
| `npm run audio` | Regenerates the code-made sound bed in `public/audio/` |
| `npm run still` | Renders one frame of `Main` to `out/still.png` |
| `npm run render` | Renders `Main` to `out/aineedhealth-30s.mp4` |
| `npm run build` | Runs `data` and then `render` |

## Generation tools

| Script | Purpose | Notes |
| --- | --- | --- |
| `tools/data.cjs` | Runs the real engine on the video scenarios | Requires `src/engine.js` from the repository root |
| `tools/audio.cjs` | Generates the sound bed (pad, whooshes, impacts, ticks) | No third-party samples or music |
| `tools/gen_voice.py` | Narration with OmniVoice (the engine used by VoiceStudio) | Python environment with `omnivoice` installed |
| `tools/fit_voice.cjs` | Fits OmniVoice takes into the existing timeline | Uses the FFmpeg binary bundled with Remotion; the path is Windows-specific |
| `tools/narrate.cjs` | Earlier narration with Piper | Expects a Piper installation with an ASCII path |
| `tools/narrate.ps1` | First narration pass with the Windows voice (Zira) | Legacy; Windows only |

The `narrate` script in `package.json` runs the legacy Windows voice pass and overwrites the narration files. It is kept for reference only. Use `gen_voice.py` followed by `fit_voice.cjs` for the current narration.
